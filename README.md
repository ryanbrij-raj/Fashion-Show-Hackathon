# The Jerry

**Your closet. Your style. Right now.**

AI styling that starts with what you already own. Built for *Runway to Reality: AI Fashion Hackathon* (GDG Brooklyn × Vonage).

## Problem

Most fashion AI answers "what should you buy?" The Jerry answers "what can you rediscover?" — it closet-first ranks: wear it as-is → restyle it → substitute something you own → only then suggest buying the one missing piece.

## Solution

Four connected experiences, all backed by the same closet, style profile, and live camera:

- **Rescue My Closet** — show a forgotten garment, Gemini identifies it, then builds outfits around it from clothes you already own.
- **Style Me Now** — tell it where you're going; it returns three outfits (Safe / Current / Push Me) from your closet, weighted by your style, fit, and today's Trend Radar.
- **Trend Radar** — ~50 cached current fashion trends, personalized against your style, closet, and fit with a deterministic match score.
- **Style Like Someone** — decode the recognizable fashion language of any real person or fictional character and translate it into your own wardrobe (never a costume copy).

Every outfit selection can launch **AI Stylist Mode**: a full-screen live camera session (Vonage Video) where Gemini walks you into the outfit step by step, then critiques the finished look and produces a shareable Look Card.

## Architecture

```
app/            Next.js App Router pages + API route handlers
  api/gemini/*  Server-only Gemini endpoints (garment, style, outfits, persona, critique, stylist, trends)
  api/vonage/   Vonage Video session/token endpoint
components/     UI, grouped by domain (editorial, video, closet, outfits, trends, persona, stylist)
lib/
  gemini/       Gemini client, per-feature prompts, per-feature service functions
  vonage/       Server-side Vonage Video session/token creation
  scoring/      Deterministic match-scoring engine (style/closet/fit/trend/persona)
  trends/       Loads data/trends.json, runs personalization
  image/        Camera frame capture (canvas resize + JPEG compression)
  storage/      localStorage wrapper (SSR-safe)
  demo/         Hand-authored Demo Mode dataset
  persona/      Non-Gemini fallback outfit builder for cached personas
schemas/        Zod schemas — validate every Gemini structured response
types/          Shared TypeScript domain types
data/           trends.json / trends.demo.json (~50 trends), personas.json (12 cached personas)
scripts/        update-trends.ts — the live trend-refresh pipeline
```

### Gemini

All Gemini calls happen server-side (`lib/gemini/client.ts` is marked `server-only`) using `@google/genai` and `ai.models.generateContent` with `responseMimeType: "application/json"` + a hand-built response schema. Every response is then **re-validated with Zod** (`schemas/index.ts`) before it reaches the UI — malformed output gets one retry, then a typed error the route can react to instead of crashing.

Ten dedicated prompts (`lib/gemini/prompts.ts`), one per job: garment recognition, style discovery, rescue outfit generation, Style Me Now, trend extraction, persona decoding, persona outfit generation, final critique, and AI Stylist step-by-step instructions. Every prompt enforces the same hard rules: clothing only (never body/attractiveness), no fabricated brands/materials/prices, closet-first, never insult a garment.

Trend and persona personalization scores are **never** generated by Gemini — they come from `lib/scoring/index.ts`, a small set of pure, documented functions (`calculateStyleMatch`, `calculateClosetReadiness`, `calculateFitMatch`, `calculatePersonalTrendMatch`, `calculatePersonaMatch`). Gemini is only asked to *explain* a score that's already been computed.

### Vonage Video

`app/api/vonage/session/route.ts` creates a real Vonage Video session + publisher token server-side (`@vonage/server-sdk` + `@vonage/video`) when `VONAGE_APPLICATION_ID` / `VONAGE_PRIVATE_KEY` are configured. The client (`components/video/useCameraStage.ts`) dynamically imports `@vonage/client-sdk-video`, connects, and publishes — the resulting `MediaStream` is mirrored into a plain `<video>` element so the same `captureVideoFrame()` canvas utility works identically whether Vonage is live or not. If Vonage isn't configured (or the session/publish call fails for any reason), it falls back to a local `getUserMedia` preview automatically — the app never dead-ends on a camera failure. A "Powered by Vonage Video" badge appears only when a real Vonage session is live.

### Trend Radar

`data/trends.json` ships ~50 pre-computed trend concepts (garments, silhouettes, materials, colors, patterns, styling techniques, footwear, accessories, aesthetics), each with source attribution and a **Trend Signal** (0–100):

```
trendScore = 0.40 × recency + 0.35 × cross-source presence + 0.25 × source authority
```

`data/trends.demo.json` is an identical, frozen copy used so Demo Mode never depends on the live file changing. `scripts/update-trends.ts` (`npm run update-trends`) is the real refresh pipeline: it pulls public RSS feeds from Vogue, GQ, Elle, Harper's Bazaar, Esquire, Who What Wear, Highsnobiety, and Hypebeast (skipping any that 404 or fail — no paywall bypass, no auth bypass, no scraping behind logins), extracts and clusters trend concepts with Gemini (falling back to a small built-in keyword taxonomy if no API key is set), scores them with the same formula above, and writes the top 50 back to `data/trends.json`.

### Recommendation Engine

`lib/scoring/index.ts` documents every heuristic used across the app:

- `calculateStyleMatch` — style-tag overlap weighted by the user's onboarding weights
- `calculateClosetReadiness` — % of an outfit/trend's required categories already owned
- `calculateFitMatch` — adjacency between preferred fit and a garment's fit language
- `calculatePersonalTrendMatch` — `0.35×style + 0.30×closet + 0.15×fit + 0.20×trendStrength`
- `calculatePersonaMatch` — style-tag overlap between a persona and the user's taste/closet

### Style Like Someone

Persona metadata (`data/personas.json`) is cached for 12 personas (Tyler the Creator, Zendaya, A$AP Rocky, Timothée Chalamet, Princess Diana, Steve Jobs, James Bond, Bruce Wayne, Tony Stark, Wednesday Addams, Miles Morales, Don Draper) — style/silhouette/color/material metadata only, never biographical claims, never physical description. Looking one of these up works **even with no Gemini key**, since it's just a JSON lookup. Anyone else typed in gets decoded live via Gemini (`personaAnalysisPrompt`). If Gemini isn't available for outfit generation, `lib/persona/fallback.ts` builds a deterministic (non-AI) outfit from whichever closet pieces share the most style tags with the persona, so the flow never dead-ends.

Every persona outfit reports a **Style Similarity** breakdown (silhouette / color language / layering / footwear / accessories) that is explicitly about clothing only — the UI and prompts are written to never imply physical resemblance.

### Privacy

- Camera frames are only ever sent to Gemini for the single request that needs them; they are not stored server-side or logged.
- Every clothing-analysis prompt explicitly instructs Gemini to describe *garments only* — never body shape, weight, attractiveness, or any physical characteristic.
- Sizing comes from user-entered text fields only; the app never claims to measure a body from video, and every sizing surface shows: *"Sizing varies by brand. The Jerry uses your preferences to estimate compatibility. Always check the retailer's size chart."*

```bash
npm install

```

Open [http://localhost:3000](http://localhost:3000).

### Environment Variables

All optional — the app runs completely via Demo Mode with none of them set. See `.env.example` for details.

| Variable | Required for | Where to get it |
|---|---|---|
| `GEMINI_API_KEY` | Live garment/style/outfit/persona AI | [Google AI Studio](https://aistudio.google.com/apikey) |
| `GEMINI_MODEL` | (optional override, defaults to `gemini-3.6-flash`) | — |
| `VONAGE_APPLICATION_ID` | Live Vonage Video session | Vonage Developer Dashboard → create a Video Application |
| `VONAGE_PRIVATE_KEY` or `VONAGE_PRIVATE_KEY_PATH` | Live Vonage Video session | Downloaded alongside the Application ID |

Secrets are read only inside `server-only`-marked modules (`lib/gemini/client.ts`, `lib/vonage/server.ts`) and API route handlers — never imported into a client component, so they never reach the browser bundle.

### Updating Trends

```bash
npm run update-trends
```

Pulls current public fashion RSS feeds, re-clusters trend concepts, rescoring, and rewrites `data/trends.json`. Requires network access; `GEMINI_API_KEY` is optional (falls back to a smaller built-in keyword taxonomy without it). Safe to run repeatedly — sources that are unreachable are simply skipped, and it merges with the existing file rather than starting from scratch.

## Demo Mode

Click **Try Demo Mode** on the landing page (or `/onboarding?demo=1`). It instantly loads a coherent, hand-authored dataset — a style profile, a 7-piece closet, a rescue item (brown corduroy overshirt), and a Tyler-the-Creator persona example — and exercises every screen with zero API credentials. A **Demo Mode** badge stays visible in the nav the whole time so it's never confused with a live result. If a live Gemini/Vonage call fails outside of Demo Mode, the app degrades to the same kind of representative data automatically, with a visible note that it's a fallback.

## Hackathon Demo (~90 seconds)

1. Dashboard — *"Most fashion AI tells you what to buy. The Jerry starts with what you already own."*
2. Point at the personalized Trend Radar hero: *"Instead of blindly following trends, Gemini determines which ones actually fit me."*
3. Rescue flow — hold up the corduroy overshirt, Gemini reads it, outfits build around it.
4. Style Like Someone — type "Tyler, the Creator," watch the style get decoded, then translated into the existing closet.
5. Wear This Look → AI Stylist Mode (Vonage Video) → Check My Look → Look Card.
6. Close: *"You didn't need someone else's wardrobe. You needed a new way to see your own."*

## Known Limitations

- Garment recognition confidence depends heavily on lighting/framing — the UI surfaces the model's own confidence score rather than hiding uncertainty.
- The cached Trend Radar dataset reflects one snapshot in time (`updatedAt` is shown on every trend); `npm run update-trends` is required to refresh it.
- Persona style decoding is drawn from general public fashion coverage/knowledge, not a verified, exhaustive archive — treat it as a stylist's informed read, not a citation.
- `lib/persona/fallback.ts` produces a simpler, less nuanced outfit than a live Gemini call when no API key is configured for an uncached persona.

## Future Work
